Retrieved 2026-10-21. This project is independently assembled and is not affiliated with the sources.

- Vocabulary: https://github.com/drkameleon/complete-hsk-vocabulary (MIT; data/HSK-LICENSE.txt). Selected entries with old-1 through old-6 tags. First form provides initial gloss; not a complete pronunciation dictionary.
- Character dictionary: https://github.com/skishore/makemeahanzi, dictionary.txt (LGPL v3 or later; data/HANZI-LICENSE.txt, data/LGPL.txt and data/GPL.txt). Selected entries are transformed into the hskN-core.json datasets, with Vietnamese short glosses added. Level is derived from earliest vocabulary occurrence, not an independently official character syllabus. Full original dictionary and conversion provenance are in SOURCE_DATA/ in the GitHub package.
- Hanzi Writer: https://github.com/chanind/hanzi-writer v3.5.0 (MIT; vendor/HANZI-WRITER-LICENSE.txt).
- Stroke data loaded on demand: https://github.com/chanind/hanzi-writer-data v2.0.1 (Arphic Public License; vendor/STROKE-DATA-LICENSE.txt). This data is not bundled as an offline pack. Runtime URL: https://cdn.jsdelivr.net/npm/hanzi-writer-data@2.0.1/{character}.json

- Vietnamese short glosses, 25 examples and 6 usage notes: newly authored for this app; not a reviewed full HSK curriculum. Character glosses are broad aids, not translations applicable in every word. Historical etymology notes retain English source text, missing values remain explicitly missing.

## Vietnamese enrichment — v2, 2026-10-21

- **CVDICT**, Phong Phan, CC BY-SA 4.0, derived from CC-CEDICT. Original upstream https://github.com/ph0ngp/CVDICT returned 404 at retrieval. Preserved mirror: https://github.com/phucbm/xue-hanzi/blob/main/src/data/CVDICT.u8. The raw file contains its author's attribution, copyright provenance and CC BY-SA 4.0 license notice. The mirrored app's code was not copied. Vietnamese dictionary senses in hskN-core and words-hskN are selected and formatting-normalized derivatives under CC BY-SA 4.0. Raw source with header retained in SOURCE_DATA/VI_SOURCES/CVDICT.u8. `viOrigin` distinguishes original short glosses and imported glosses; `dictionaryVi` retains distinct pronunciations. Not all translations are manually reviewed.
- **Kai Hanzi HSK × Sino-Vietnamese dataset**, https://github.com/xkhanhs/hsk-sino-viet, CC BY 4.0. Data from Kai Hanzi (https://kaihanzi.com/chu), CC BY 4.0. Imported 659 matching character records and 406 component records. The source's HSK 3.0 teaching levels do not replace the app's existing HSK 2.0 derived levels. Memory hooks are mnemonic aids, not historical evidence. The ⺍ gloss was edited to remove the implication that 'light of knowledge' is its dictionary meaning. Dataset contains components beyond Kangxi radicals. Copy of source license in data/KAI-LICENSE.txt.
- **Tatoeba**, https://tatoeba.org/en/downloads, API https://api.tatoeba.org/v1/sentences. 667 Chinese sentences having direct Vietnamese translations in the retrieved export, excluding flagged unapproved/orphan records; 614 selected simplified-script sentence/translation pairs are added. Sentence texts retained without translation or script conversion; corpus subset filtered by length/script and a small profanity filter. Every retained pair includes Chinese and Vietnamese sentence IDs, owner names, and both licenses. Each side is CC BY 2.0 FR in this export. In-app source links provide attribution for each contributor. Community data, not graded or fully proofread HSK learning material. No audio redistributed.
- **Dong Chinese**, https://www.dong-chinese.com/wiki/学, CC BY-SA 4.0. Vietnamese paraphrase of the 学 character-origin note included as `etymology-vi.json[学]`, adapted by Hanzi Việt; source link shown beside it. No historical images redistributed.
- **Make Me a Hanzi dictionary**: Vietnamese structured summaries preserve the type/semantic/phonetic metadata from the existing LGPL source. A summary is not a full translation of all historical notes; detailed coverage remains explicitly incomplete.
- Four missing dictionary phrases and 30 additional grammar notes were newly authored for this revision. Their examples do not establish official HSK syllabi, and grammar notes are not comprehensive per-character lessons.

These attribution and share-alike terms apply to the specific imported/adapted fields and files, not to unrelated independently authored app code. Raw inputs, selected output provenance and SHA-256 hashes accompany the GitHub package.
