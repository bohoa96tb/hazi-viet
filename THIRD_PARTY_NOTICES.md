# Sources and notices — Hanzi Việt v1
Retrieved 2026-10-21. This project is independently assembled and is not affiliated with the sources.

- Vocabulary: https://github.com/drkameleon/complete-hsk-vocabulary (MIT; data/HSK-LICENSE.txt). Selected entries with old-1 through old-6 tags. First form provides initial gloss; not a complete pronunciation dictionary.
- Character dictionary: https://github.com/skishore/makemeahanzi, dictionary.txt (LGPL v3 or later; data/HANZI-LICENSE.txt, data/LGPL.txt and data/GPL.txt). Selected entries are transformed into the hskN-core.json datasets, with Vietnamese short glosses added. Level is derived from earliest vocabulary occurrence, not an independently official character syllabus. Full original dictionary and conversion provenance are in SOURCE_DATA/ in the GitHub package.
- Hanzi Writer: https://github.com/chanind/hanzi-writer v3.5.0 (MIT; vendor/HANZI-WRITER-LICENSE.txt).
- Stroke data loaded on demand: https://github.com/chanind/hanzi-writer-data v2.0.1 (Arphic Public License; vendor/STROKE-DATA-LICENSE.txt). This data is not bundled as an offline pack. Runtime URL: https://cdn.jsdelivr.net/npm/hanzi-writer-data@2.0.1/{character}.json
- Optional fonts: Google Fonts Be Vietnam Pro and Noto Serif SC. Network stylesheet; system fallbacks are available. No font binaries redistributed.
- Vietnamese short glosses, 25 examples and 6 usage notes: newly authored for this app; not a reviewed full HSK curriculum. Character glosses are broad aids, not translations applicable in every word. Historical etymology notes retain English source text, missing values remain explicitly missing.
